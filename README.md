
# Scrum GitHub Practice

Repositorio de aprendizaje para practicar la
gestión de proyectos con Scrum y GitHub Projects.

## Objetivo

Aprender a configurar un repositorio de GitHub,
organizar un Product Backlog, planificar Sprints
y realizar seguimiento al desarrollo de software.

## Proyecto de ejemplo

Desarrollaremos una aplicación de gestión de tareas.

Funcionalidades previstas:

- Crear tareas.
- Listar tareas.
- Editar tareas.
- Marcar tareas como completadas.
- Eliminar tareas.

## Metodología

Utilizaremos Scrum para organizar el desarrollo.

Las historias de usuario y tareas se registrarán
mediante GitHub Issues.

La planificación y el seguimiento se realizarán
con GitHub Projects.

## Pruebas de GitHub

Este repositorio se utiliza para aprender
a crear y administrar Pull Requests.
